# Order2Me

**Order2Me** is a fresh meat and fish delivery web application that allows users to browse categories, add items to their cart, and place orders conveniently. The app is mobile-responsive and offers a seamless user experience.

---

## Features
- 🛒 **Browse Products**: Explore categories like Chicken, Eggs, Exotics, and Fish & Seafood.
- ⭐ **Popular and New Arrivals**: Highlighted sections for trending and newly added items.
- 🧾 **Cart Management**: Add items, choose quantities, and review your cart before checkout.
- 📱 **Mobile Responsive Design**: Optimized for all devices with a sleek, user-friendly interface.
- 🔐 **User Authentication**: Secure registration and login with OTP verification.
- 💳 **Order and Checkout**: Place orders and manage your purchase history.

---

## Tech Stack
- **Frontend**: React, React-Bootstrap
- **Backend**: Node.js (Express.js)
- **Database**: PostgreSQL
- **Hosting**: AWS (S3, RDS, EC2)
- **Additional Services**: 
  - DynamoDB for real-time data (if required).
  - AWS SNS for notifications.
